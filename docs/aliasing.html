Two-return model: one surface-clutter return moves in aliased Doppler as PRF changes; one subsurface target stays fixed at 0 Hz and 6.74 km.

1

Fixed geometry

One surface-clutter point and one subsurface target. Their physical locations stay fixed.

R = √(h² + x²); depthapp = (R − h) / n

2

Depth alignment

The two returns already share the same apparent-depth cell; PRF decides whether their Doppler also matches.

Δdepth = depthsurface − depthtarget

3

Two-return PRF trace

The surface return moves across aliased Doppler while the subsurface target remains at 0 Hz.

falias = ((fD + PRF/2) mod PRF) − PRF/2

4

Doppler × depth

The clutter return interferes only when it enters the target cell in both Doppler and depth.

overlap: |falias| ≤ 25 Hz and |Δdepth| ≤ 0.15 km
